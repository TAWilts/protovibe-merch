So wird eine freigegebene Version installiert

Der laufende Container erhält keine Rechte, Git oder Docker selbst zu steuern. Dadurch kann ein App-Login kein Software-Update auslösen.

  1. Die Release-Notizen prüfen.
  2. Auf der Synology das versionierte Container-Image der gewünschten Release-Version abrufen.
  3. Das Projekt kontrolliert neu starten. Die Daten unter data/ bleiben davon unverändert.
